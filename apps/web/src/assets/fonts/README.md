# Fonts

`inter-latin-wght-normal.woff2` is the Latin subset of Inter (variable, weights 100 to 900), byte-identical to the file in
`@fontsource-variable/inter` 5.3.0. Inter is licensed under the SIL Open Font License 1.1; the license text ships with the
build as `/licenses/Inter-OFL.txt` (docs/02 section 4.3, D-113).

Only Latin is included; Chinese always uses the system fonts. No other font file is downloaded, and SF Pro / SF Mono are
never bundled (docs/02 section 1).
