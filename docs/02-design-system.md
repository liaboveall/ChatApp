# 02 设计规范（Apple Liquid Glass 风格，桌面优先）

> 设计令牌的唯一来源是 `apps/web/src/design/tokens.ts`，改动后运行 `bun run design:contrast`。组件通过 `bun run storybook` 预览。
> 历史 D 阶段原型和评审数据保存在[清理前归档](https://github.com/liaboveall/ChatApp/tree/v2-pre-cleanup-2026-10-20/design)，当前使用下方规范与 React 组件维护界面。

## 1. 风格来源

- **Apple Liquid Glass**：2025 年随 iOS 26 / macOS 26 推出。2026 年 WWDC（iOS 27 / macOS 27）又做了修正，重点放在**可读性**上：
  - 玻璃更善于"化开"背后复杂的内容；
  - 边缘加深、高光更亮；
  - macOS 工具栏回到统一的磨砂效果；
  - 系统设置里新增透明度滑块，可在"清透"到"着色"之间调节。
- **布局与质感的参考 App**：macOS 的「信息」「邮件」「备忘录」。
- **原则**：
  - 内容优先：界面要退后，让消息成为主角。
  - 清晰：层级明确，文字始终可读。
  - 层次：导航层"浮"在内容层之上。

### 法律与素材红线
- **不打包 SF Pro / SF Mono 字体文件，也不使用 SF Symbols。** Apple 的授权只允许在 Apple 平台上使用它们。除了 Inter（OFL 协议，可以自托管，见 4.3）之外，我们只在 CSS 中引用系统字体名，由用户设备上已安装的字体来显示。
- 不使用 Apple 的商标、Logo 和图标，不照搬 Apple App 的界面素材。我们借鉴的是设计语言，应用图标自行设计。

### 方向要点（2026-11-13 重构，取代 D1 的"三块浮动面板"）

不收集 Apple 的界面截图作为情绪板（红线），改用下面这些可检验的要点：

- **内容铺满窗口，控件悬浮其上**：窗口本身是一整块实底（`--bg-content`），会话直接铺在上面，四边到头；侧栏、工具栏的两枚胶囊、输入栏和 Inspector 是浮在它上面的玻璃。壁纸（淡渐变加几块强调色的光）只铺在侧栏下面，在会话开始之前淡出，主区域的文字从不落在壁纸上。
- **滚动边缘**：内容滚到工具栏和输入栏下面时，向窗口底色淡出，而不是被一条硬边截断；工具栏本身不是一条实心的栏。
- **玻璃分四种材质**：浮在壁纸上的（侧栏，随透明度档位）、承载文字的（标题胶囊、输入栏、菜单、弹层、Inspector，有不透明度下限）、只放图标的（工具胶囊、附件按钮、"回到最新"，下限低得多，最通透）、放在实底上的小件（悬停工具条、审批卡，不开模糊）。见第 2 节。
- **可读性高于通透**：文字对比度先于玻璃效果。承载文字的玻璃因此几乎不透明，玻璃感来自边缘：外侧的发丝线、顶部的受光边、两角的高光边和柔和的投影。真正通透的只有不承载文字的图标玻璃和壁纸上的侧栏。
- **按的是胶囊，写的是圆角井**：按钮、图标按钮、分段控件、搜索框都是胶囊或圆片；输入框、文本域、下拉框是 12px 圆角的井。悬停改底色、按下缩小、键盘焦点画焦点环，三种反馈各改一个属性。
- **经过的是灰，选中的才是强调色**：菜单、命令面板、@候选里指针或键盘经过的行用灰色填充；持久的选中（侧栏里打开的会话、设置里当前的分区）才用强调色实底配白字。
- **状态不只靠颜色**：在线用实心点、离开用缺一角的点、离线用空心圈；打开的会话是一整块实底加反白的字；开关在轨道里画"开"的竖线和"关"的圆圈；密码规则用图标加文字。
- **圆角同心，气泡带尾巴**：外层圆角 = 内层圆角 + 间距。浮动面板 22px、里面的行 16px；弹层 26px、里面的卡片 16px。圆角一律是圆弧：`corner-shape: squircle` 把曲线收在同一个半径框里，同样的数值在支持它的引擎里明显更尖，面板与内容不再同心，各浏览器也不一致，所以只留给按它调过尺寸的频道小方块。

## 2. 玻璃材质的使用规则

- **导航与控件层**使用玻璃：侧边栏、工具栏的标题胶囊和工具胶囊、输入栏与附件按钮、Inspector、弹出菜单、弹层（sheet）、⌘K 命令面板。
- **内容层保持实底**：消息列表、消息气泡、长文本区域都**不**用玻璃，保证可读性。
- 壁纸只在侧栏下面：窗口底色之上铺 `--bg-app`，再叠几块柔边的光，每层不超过 24%（浅）/ 34%（深）；侧栏玻璃的对比度检查以它为前提。上方和中间的光取强调色及其邻近色相；下方那一块在深色主题里也是强调色的邻近色相，在浅色主题里固定是一块暖杏色（`--wallpaper-warm` #F2A468，不随强调色变），米白的底才不会被冷色的光带偏。登录等页面整屏都是壁纸，卡片是承载文字的玻璃，所以那里的光可以更亮（40% / 58%）。
- **玻璃分四种材质**（D-109 的三种，2026-11-13 增加图标玻璃）：

| 材质 | 用在哪里 | 不透明度 | 模糊 |
|---|---|---|---|
| `.glass` | 只浮在壁纸上、背后颜色已知的层：侧栏 | 随下面的四档；"着色"档叠加强调色调 | 随档位 |
| `.glass-text` | 承载文字、背后可能是任意内容的层：标题胶囊、输入栏、Inspector、菜单、弹层、命令面板、设置面板 | 取所选档位和下限中较大的一个：下限 90%（浅深相同）。不带强调色调，"着色"档改为发丝线里淡淡的强调色 | 随档位 |
| `.glass-clear` | 只放图标的控件：工具栏右侧的工具胶囊、输入栏左侧的附件按钮、窄窗口的菜单按钮、"回到最新" | 下限 44%（浅）/ 56%（深）；"着色"档 70%，"不透明"档 100% | 档位模糊的一半（小圆片下面模糊太宽只剩一片平色） |
| `.glass-lite` | 放在实底上的小件：审批卡、悬停工具条、"正在输入"的小标签 | 同 `.glass-text` | 不开模糊 |

- **为什么有下限**：背后是纯黑图片时，浅色玻璃上的主文字 / 次要文字 / 占位文字，清透 45% 只有 4.06 / 1.50 / 1.27:1，标准 62% 为 6.95 / 2.66 / 2.25:1；深色玻璃在纯白图片上同理。下限由脚本按黑白两个极端反推（留 4.6:1 的余量）。**图标玻璃的下限是另一条**：图标用主文字色，只需 3:1（非文字对比度），脚本同样按黑白两个极端反推（留 3.1:1），所以它可以低到 44% / 56%，真正看得见下面经过的内容。图标玻璃上**不放文字**。
- 用户可以在设置里调节透明度，分四档（只有 `.glass` 完全跟随；其余取档位与各自下限的较大值）：

| 档位 | 背景不透明度 | 模糊 | 说明 |
|---|---|---|---|
| 清透 | 45% | 22px | 最有玻璃感 |
| 标准（默认） | 62% | 28px | |
| 着色 | 80% | 32px | 叠加强调色调 |
| 不透明 | 100% | 无 | 浏览器报告系统开启了"减少透明度"（`prefers-reduced-transparency: reduce`）时强制使用，此时**所有**玻璃都变成不透明、不模糊、不带色调。不支持这个媒体查询的浏览器，由用户在设置里手动选择 |

- **边缘处理**：外侧 1px 发丝线，内侧顶部 1px 受光边，再叠一圈两角更亮的高光边（1px 渐变描边，用 mask 镂空）和柔和的投影。投影分三档：小控件、面板与弹出层、弹层与对话框。这些都不改变文字所站的底色，对比度检查量的就是那个底色。
- **性能**：同一屏最多 6 处 `backdrop-filter`：侧栏、标题胶囊、工具胶囊、输入栏、附件按钮各一个，再加一个弹出的层；后四个面积都很小。打开模态层（命令面板、设置、对话框）时，被遮住的标题胶囊、工具胶囊、输入栏、附件按钮和"回到最新"去掉模糊。悬停工具条、审批卡、"正在输入"不开模糊（D-110）。不使用折射类的 SVG 滤镜。

## 3. 桌面布局

```
┌────────────────────────────────────────────────────────────────────────┐
│ ╭ Sidebar ──╮ ╭ 头像 · 名称 › ╮                    ╭ ✦  ⋯ ╮ ╭ Inspector ╮ │
│ │ (glass)   │ ╰───────────────╯                    ╰──────╯ │ (glass)   │ │
│ │ search ⌘K │                                               │ [详情|助手]│ │
│ │ pinned    │      Timeline（直接铺在窗口上，虚拟列表）        │           │ │
│ │ channels  │      max content width 820px                  │           │ │
│ │ groups    │                                               │           │ │
│ │ DMs       │                                               │           │ │
│ │ agent     │  (+) ╭ 发消息…                     ☺  ⬆ ╮     │           │ │
│ │ me        │      ╰──────────────────────────────────╯     │           │ │
│ ╰───────────╯                                               ╰───────────╯ │
└────────────────────────────────────────────────────────────────────────┘
   304px (260–400, draggable)                                     340px
```

**窗口与悬浮层**：窗口是一整块 `--bg-content`。侧栏和 Inspector 是距窗口边缘 8px 的玻璃面板（圆角 22px，`--radius-window`）；主区域没有自己的边框和圆角，它就是窗口。工具栏不是一条栏，而是左右两枚浮在内容上的胶囊，中间留空；输入栏浮在内容底部。内容在这两处向窗口底色淡出（滚动边缘）。

**侧边栏**
- 最上面是搜索胶囊（提示 ⌘K）和一枚图标玻璃的"新建"圆片。
- 下面依次是：置顶、频道、群组、私信、助手（Agent 会话）。
- 每一项显示：头像或图标（40px）、名称、最后一条消息预览（可以切换为紧凑模式不显示）、时间、未读徽标（强调色胶囊）、免打扰图标。
- 头像的形状区分对象：人、群组和助手是圆形，频道是圆角方块（强调色 14% 底色配 `#` 号，用强调色文字）。头像规则见 4.6。
- **打开的会话**是一整块强调色实底（与气泡同一组颜色），名称、预览和时间都用白字，未读徽标反白，频道方块换成白色 22% 的衬底。实底的形状加反白的文字就是"选中"，不只是一种色相。"选中"以链接的 `aria-current="page"` 为准，这是路由给当前会话的链接写的值。
- **草稿**：在某个会话里写了没发的内容，离开后它的那一行把预览换成红色的"草稿"加上写下的文字，发出或清空后恢复；行的无障碍名称同时说"有未发送的草稿"。当前打开的会话不显示（内容就在输入栏里）。
- 侧栏只有贴着壁纸时才用带色调的玻璃。作为抽屉盖在会话上时（宽度不足 1024px 时展开，或不足 768px），改用承载文字的那种填充（不低于不透明度下限、不带色调），否则下面的气泡会在名字后面透出一条条色带。
- 折叠成窄栏时（768–1023px），分组标题放不下名字，每个分组的开关画成头像组之间的一条短分隔线；指针或键盘焦点在上面时显示箭头，分组收起时箭头一直显示，所以被收起的会话不会无缘无故消失。开关保留名称和 24px 的点击高度。
- 侧栏宽度可以拖动（260–400px，默认 304px）；拖动条在侧栏右缘与主区域之间的空隙里，20px 宽。
- 最底部是当前用户卡片：头像和名字（打开账号设置），旁边是通知铃铛（M6，带未读数）和设置按钮。
- "新建"菜单里有"浏览频道"和"已归档"；"已归档"列出我是群主的已归档会话，可以在那里恢复。

**工具栏**
- **标题胶囊**（左，承载文字的玻璃）：会话头像和名称；副标题在频道和群组里显示成员数，在私信里显示对方的在线状态，在助手对话里显示"助手对话"。整枚胶囊是一个按钮，名称是"成员与详情"，按下打开或关闭 Inspector 的详情页，末尾的箭头在打开时转向。没有打开会话的页面上它只是应用图标和产品名，不是按钮。
- **工具胶囊**（右，图标玻璃）：助手面板、更多。窄窗口时最左边多一枚打开导航抽屉的圆片。
- 两枚胶囊之间不画任何底：内容从下面滚过，并在胶囊所在的这一带向窗口底色淡出。

**时间线**：消息内容居中，最大宽度 820px；每个气泡最宽不超过时间线的 68%。时间线占满整个主区域，从工具栏和输入栏下面滚过；第一行从工具栏下方开始，最后一行止于输入栏上方（输入栏的高度实时量进 `--composer-h`）。

**输入栏**
- 浮在内容底部的一枚圆片加一枚胶囊：左边是图标玻璃的"+"（附件），右边是承载文字的玻璃胶囊，里面依次是输入框、emoji、预览切换和发送。输入内容变多时胶囊自动长高，最高占窗口的 40%。输入框获得焦点时，胶囊显示 2px 焦点环，外面再加一圈 16% 强调色的柔光。窄窗口同样是一行，不再把输入框单独折到上一行。
- **emoji 面板**是胶囊里的一块展开区：最上面是"最近使用"（存在这台设备上、按账号分开，最多 24 个），下面按"表情与人物、手势与心情、动物与自然、食物与饮料、活动与物品、符号"分组，分组标题在滚动时停在顶部。再点一次按钮、按 Esc，或在输入栏之外按下指针都会收起；Esc 先收起面板，再按一次才退出回复或编辑。
- 按钮：附件、emoji、发送。发送键是强调色圆形按钮，输入为空时禁用。只输入一个 `/` 时，胶囊里列出助手能回应的命令。
- 输入框里有内容时，发送键左边多一个"预览消息 / 编辑内容"的图标按钮（眼睛 / 铅笔，按钮的名称就是按下去会做的事）。它放在输入行里而不是输入框上方，所以输入第一个字时胶囊的高度不变，时间线不会被顶动。
- **格式快捷键**：⌘B、⌘I、⌘⇧X 给选中的文字加上或去掉 Markdown 的加粗、斜体、删除线标记；没有选中时写下标记并把光标放在中间。选区伸进 @提及 时不动（否则名字会和它代表的人断开）。
- **拖放**：把文件拖到会话的任何位置都可以添加附件，悬停时胶囊亮起强调色的环；也可以直接粘贴图片。
- 输入法组字期间，回车只确认候选词，不发送；组字结束后按回车才发送（D-050）。
- 回复或编辑时，胶囊顶部出现一条说明（"回复 / 正在编辑"加原文摘要和取消按钮）。
- 助手对话里，输入栏上方多一枚玻璃胶囊：推理模式和重命名、删除。

**Inspector（右侧面板）**
- 一块承载文字的玻璃面板。顶部是分段控件 [详情 | 助手] 和关闭按钮。
- 详情页最上面是头像、名称和简介，下面每件事各占一组（与设置里的分组同一画法）：共享文件（M3 起）、成员、邀请链接、我的设置、会话设置；管理员还能看到封禁名单；最后是退出与归档。
- 开启了助手的会话，在设置里显示一行提示："@助手 时，最近的消息会发送给 AI 服务处理。"
- 助手页就是 Agent 面板，见第 6 节。

**提示**
- Toast 从窗口顶部中间落下（工具栏两枚胶囊之间），不盖住输入栏；它和 Tooltip 在深浅两种主题下都是深色的提示牌配白字。

**宽度适配**
- 1024–1279px：Inspector 从右侧以浮层形式弹出，不挤占时间线。
- 768–1023 CSS px：侧栏折叠成 68px 的窄栏，Inspector 弹层；低于 768 至 320 CSS px：单栏时间线，导航抽屉（在抽屉里点任何链接，包括已经打开的会话，或路径变了，抽屉就关上，D-166），Inspector 占满窗口。桌面 400% 缩放不能产生整页横向滚动（`accessibility.spec.ts` 用 320 px 宽的页面走完主流程）；代码块/表格可独立横滚。手机专用交互仍在 v1.1。

**空状态**：没有选中会话时，显示欢迎页和常用快捷键。

## 4. 设计令牌（D4 确认）

以 Tailwind v4 的 `@theme` 变量实现，颜色以 sRGB 的十六进制或 `rgb()` 书写（D 阶段的令牌表即如此，对比度脚本按 sRGB 计算；这里原先写的 OKLCH 没有采用），深浅模式通过 `light-dark()` 切换。数据源是 `apps/web/src/design/tokens.ts`（M1b 起，D-114）：它生成运行时 CSS 和 Tailwind 主题，并驱动 `bun run design:contrast`（约 2600 组对比度检查，包含在 `bun run check` 里）；改令牌必须先过它（D-111）。原型里的 `tools/tokens.mjs` 只是转出口。

### 4.1 颜色（语义命名，仿照 Apple 系统色的思路）

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--bg-app` | #F3EFE7 + 淡渐变 | #000000 + 淡渐变 | 壁纸的底色（侧栏下面、登录页） |
| `--bg-content` | #FAF7F1 | #0E0E10 | 窗口本身：时间线直接铺在上面。浅色是米白（未漂白的纸色），不是纯白；深色比玻璃更深，浮层看起来是抬起来的。它也是安装后窗口标题栏的颜色（`theme-color`） |
| `--bg-elevated` | #FFFDF9 | #1C1C1F | 弹层、卡片 |
| `--label` | rgba(28,22,12,.90) | rgba(255,255,255,.92) | 主文字 |
| `--label-secondary` | #5B564D | #B6B6C2 | 可读次要文字，不降低整块opacity |

D-092将次要/占位色改为不透明值；适用浅色背景为#FFFDF9/#FAF7F1/#F3EFE7/#EEE9DF（2026-11-13 起的米白色系；每个中性色与它取代的冷灰亮度相同或更深），深色为#0E0E10/#1C1C1F/#28282C（2026-11-13 起；更深的底只会提高浅色文字的对比度）。每个组合分别计算，不将气泡的on-accent与本表混用。玻璃层若背后内容导致最差组合不满足门槛，给文字区加足够实底的衬层或提高材质不透明度，不能通过降低文字opacity补救。D 阶段已验证全部透明度档位下的实际渲染（第 10.3 节）；hover/focus/错误/占位状态在 M1b 的组件里继续验证，静态计算不是完整无障碍验收。[WCAG文字对比度依据](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

### 4.3 字体

D4 确认（2026-10-02，D-113）：**拉丁字母和数字用 Inter，中文用系统字体，Apple 设备上仍然先用 SF。**

- **等宽字体栈**：`ui-monospace, "SF Mono", "Cascadia Code", Menlo, Consolas, monospace`

### 4.5 动效（Motion 13 的弹簧动画）

控件的三种反馈各改一个属性，叠加时每一种都看得出来：悬停改底色，按下把控件缩到 0.92–0.97（`scale`），键盘焦点画焦点环。

| 预设 | 参数 | 用途 |
|---|---|---|
| `snappy` | stiffness 500, damping 38 | 菜单、按钮反馈 |
| `smooth` | stiffness 300, damping 30 | 面板展开、切换会话 |
| `bouncy` | stiffness 400, damping 22 | 新消息插入、发送 |
| 淡入淡出 | 150–250 ms | 提示、遮罩 |

原型把三个弹簧的精确解导出成 CSS `linear()`，时长约 snappy 392 ms、smooth 506 ms、bouncy 631 ms（算法在 `tokens.mjs`）；M1b 用 Motion 14 驱动，参数不变（用到的 `layoutId` 和 `MotionConfig reducedMotion` 在 14 上正常，D-115）；系统的「减少动态效果」和设置里的开关都会让它退化为淡入淡出。

- **切换路由和会话**：优先用 View Transitions API 做过渡，浏览器不支持时直接切换。
- **元素入场**：用 `@starting-style` 实现。
- **减少动态效果**（`prefers-reduced-motion`，或在设置里开启）：所有动画都改成 ≤ 150ms 的纯透明度变化。

### 4.6 头像、输入控件与层次

- **头像**：没有上传图片时，用名字的首字加一个由 id 决定的渐变色圆盘（同一个人始终同色）。色相只从 9 个里取：15、150、178、205、232、256、280、308、342。渐变顶端的明度是 OKLCH 0.56，白色首字在整个圆盘上不低于 4.5:1；这个明度下 50–140 之间的黄色、黄绿色会变成棕色和橄榄色，所以不用。频道是圆角方块，助手是固定的紫色渐变加星形图标。
- **输入框、文本域、下拉框**：一口 12px 圆角的井（浅色是 #FFFDF9 的暖白底，深色是白色 5% 的衬底）加 1px `--control-border` 描边，灰底只留给只读和禁用的字段。悬停时描边加深；聚焦时描边位置画 2px 焦点环，外面再加一圈 18% 强调色的柔光。
- **下拉框**始终是浏览器自己的 `<select>`（键盘、首字母定位、表单都随之而来）。浏览器允许页面绘制选择器时（`appearance: base-select`，Chromium 135、Safari 27 起），弹出的列表画成一块玻璃菜单：圆角 16px，选项在指针经过时变灰，选中项加粗并在行尾打勾，开合带淡入和 4px 的位移（`@starting-style` 加 `transition-behavior: allow-discrete`，系统要求减少动态效果时只淡入）；其余浏览器保留系统自带的弹出列表，框和箭头照样是我们画的。
- **按钮**是胶囊：实底（强调色，下半部向黑色过渡 9%，只会提高白字的对比度；带一圈自身颜色的投影）、着色（强调色 12% 底）、无底、玻璃四种；图标按钮是圆片，其中 `plate` 是单独一枚图标玻璃。
- **开关**：50×30 的轨道和一枚宽拇指（28×24）；关着时轨道里远端有一个小圆圈，开着时近端有一条竖线，按住时拇指变宽。轨道自己的 1px 描边保证 3:1。
- **分段控件**：胶囊轨道里滑动的胶囊拇指，拇指带 1px 描边。**滑块**：4px 的细轨和一枚 30×20 的宽拇指。
- **确认框**（`ConfirmDialog`，不可撤销操作前的提问）是居中的小卡片（340px），标题和说明居中，两个回答并排等宽，焦点先落在"取消"上。
- **层次**：阴影分两层，一层贴着边缘的短阴影，一层范围更大的环境阴影（`--elev-1`、`--elev-2`；浮动的玻璃按离窗口的高度用 `--glass-drop-sm`、`--glass-drop`、`--glass-drop-lg`）。实底按钮顶部有一条高光、底部有一道短阴影。
- **分组**：面板里的一组行（设置、Inspector 的各段、管理页的记录）是面板自身颜色的一层浅衬底（`--group-bg`）加 1px 内描边，在玻璃上和实底上都成立，不再用带阴影的白卡片。
- **壁纸色块**：从中心向外逐渐淡出，只有正中心达到上限色调（第 2 节的上限不变），看起来是环境光而不是圆盘。

## 5. 聊天界面细节

- **气泡**
  - 自己的消息靠右，bubble-out 底配 on-accent 文字；别人的消息靠左，灰底配 label。
  - 群聊里，同一组消息的第一条上方显示发送者名字，头像放在最后一条的左下角，和「信息」App 一样。
- **时间**：鼠标悬停在气泡上（或焦点在这一行里）时，在气泡远离屏幕边缘的一侧显示发送的时刻（时:分；是哪一天由上方的日期分隔说明），排在悬停工具条外侧；带日期和秒的精确时间是它的 `title`，也始终写在这一行的无障碍名称里。它不占行内空间（否则会把气泡挤窄）；窗口宽度不足 768px 时不显示（触屏没有悬停）。
- **附件**
  - 只有图片、没有文字的消息不套气泡，图片本身就是消息（18px 圆角）；带文字时图片在气泡里。多张图片排成两列的网格，奇数张时第一张占满一行。
  - 只有一到三个 emoji 的消息同样不套气泡，放大显示。
  - 视频上叠一个播放按钮，文件显示为卡片（图标、文件名、大小、下载按钮）。
  - 图片加载前先显示 thumbhash 模糊占位图。
- **回复**：气泡上方显示引用条，写着对方名字和原文摘要。点击后跳到原消息，原消息高亮 1 秒。
- **@提及**：提及显示为高亮胶囊。@我的消息整条带淡淡的强调色背景。
- **系统消息、撤回、删除**：居中的小号灰字。
- **机器人徽标**：Agent 的名字旁边有"机器人"标签（时间线里发送者名字之后，资料卡里用户名之下），防止有人用"助手"之类的显示名冒充；显示名本身也不能使用保留名。
- **资料卡**：群聊和频道里，消息旁的头像是一个按钮（名称是"查看某某的资料"），按下在头像旁弹出一张玻璃卡片：头像与在线状态、名字、用户名、简介，以及"发消息"（打开或新建与对方的私信）。自己和机器人的卡片没有"发消息"。Esc 或在卡片之外按下指针关闭。
- **加入前的历史**：
  - 新成员的时间线顶部显示"你于某时加入，之前的消息不可见"；
  - 引用了加入前消息的回复，引用条显示"原消息不可见"。
  - 共享助手显示“仅总结所有当前成员都能看到的讨论”；新成员加入后说明范围变化，并提供个人面板入口。
- **正在输入**：输入栏上方的一枚小玻璃标签，里面是三个跳动的圆点和谁在输入；它浮在会话之上，所以有自己的底。
- **分隔条**："以下为新消息"用强调色细线加文字；日期分隔是居中的一行小号次要文字，不加底色。
- **会话起点**：时间线顶部在会话的开头只显示一行居中的小字（图标加"这是 … 的开始"）；如果那里是这个人可见范围的边界（后加入），改用带底色的说明块，见下面"加入前的历史"。
- **右键菜单**：回复、复制、编辑、撤回、删除（仅自己）、举报、交给助手（把这条消息带进助手面板）。
- **悬停工具条**：鼠标悬停在气泡上时浮出，含回复和更多（表情回应仍未实现）。它是一枚不开模糊的玻璃胶囊，贴在气泡远离屏幕边缘的一侧、靠近第一行的高度，不遮挡发送者名字，也不占行内空间；窗口宽度不足 768px 时气泡旁没有位置，改为压在气泡远端的上角。
- **文件卡片**：左侧是强调色底的文件图标，中间是文件名和大小，右侧的下载箭头表示整张卡片可下载。放在气泡里时，卡片取气泡自身颜色的内嵌色（与引用条同一做法），文字沿用气泡已校验的对比度。
- **代码块**：用 Shiki 高亮，浅色和深色各一套主题，右上角有复制按钮。
- **发送状态**：发送中气泡去饱和，不降低文字不透明度（整个气泡降到 0.6–0.72 时，白字对蓝色气泡只有 2.66–3.32:1）；失败时气泡旁出现红色感叹号，点击可以重试或删除。
- **删除状态**（M7）：异地确认未完成时显示“删除待完成，内容仍可能可见”，可查看进度；完成后才显示撤回/删除占位。错误给明确重试入口，不把202当成功，也不允许重复点击扩大目标。
- **回到最新**：离开底部时，输入栏上方的右侧浮出一枚图标玻璃的圆形按钮，并显示期间新到的消息数。

## 6. Agent 相关界面

- **Agent 的消息**：头像是 ✦ 图标。流式输出时，气泡边缘有流光渐变描边，风格参考 Apple Intelligence；输出完成后描边淡出。
- **流式文本**：用 Streamdown 渲染，未写完的 Markdown 也不会乱掉；末尾带闪烁的光标。
- **工具调用卡片**
  - 默认折叠成一行："正在搜索消息…" → "✓ 找到 12 条相关消息"，可以展开查看参数和结果摘要。
- **审批卡片**
  - 一张玻璃卡片，写明要做什么、做在哪里（比如"发送到 #项目组"），并完整预览将要发送的内容。
  - 三个按钮：批准（强调色）、修改、拒绝；卡片上显示剩余有效时间。
  - 运行暂停等待审批时，Agent 当前的回复先收尾：流光描边停止，末尾显示"等待 @某人 批准"。批准后，接下来的输出显示为一条新回复。
  - 通知中心和推送会同步提醒（M6）。
- **重新生成**（D-036）：
  - 悬停工具条上的“重新生成”会**替换**原回复，消息视图不保留旧版本；旧 run 副本按隐私保留期处理。
  - 只对发起人显示：
    - Agent 会话和面板里，只出现在最近一条回复上；
    - 群里 24 小时内可用；
    - 执行过任何业务效果（含提醒/记忆）、有待审批或仍在运行的回复不显示按钮。
- **助手面板（Inspector 的"助手"页）**：自上而下是一段私有对话的四个部分。
  - 顶栏：当前这段对话的名字（一个不带边框的原生下拉框，用来切换历史对话或回到空白的新对话），右侧是重命名、删除和"新建助手对话"三个图标按钮；已经在空白的新对话里时，"新建"按钮禁用。
  - 对话流：和当前会话绑定，只有自己可见，顶部用一行带锁图标的小字说明。自己的请求是靠右的强调色淡底气泡，助手的回答是面板上的正文，上方标"助手"；回答下面是用量小字、可展开的工具步骤和"插入输入框"按钮（起草的结果**不会**直接发出）。还没有对话时显示空状态。
  - 请求选项：读取范围（"当前会话"默认 / "所有可访问会话"）和推理模式（快速 / 深入）各占一行，紧贴在输入框上方，写请求时就能看到。已有对话时，读取范围下面显示一句"切换范围会开始新的上下文"（D-051）；空白的新对话没有可丢失的上下文，不显示这句。切换范围开启新上下文段，旧段不自动送给模型。
  - 输入区：一排快捷操作胶囊（总结未读、翻译、起草回复），下面是随内容长高的输入框，发送键是框内的圆形强调色按钮。Enter 发送，Shift+Enter 换行，输入法组字期间的回车只确认候选词（D-050）。最下面是一行 AI 服务说明。
- **⌘K 命令面板**：居中的玻璃弹层。可以在这里跳转会话、执行命令（如 `/总结`、`/翻译`、`/提醒我 …`），或直接向 Agent 提问。
- **key来源切换**：显示当前来源；切换创建空白上下文段，说明旧私有上下文不会自动带入。BYOK失败时按钮为“使用站点额度发起新请求”，不自动填回原文/图片；隐私说明可查看，鼓励文案仍只讲好处。
- **任务与时区**：提醒/定时消息卡完整显示日期、时区、UTC偏移、来源设备和取消入口。设备安全撤销前显示受影响任务；普通退出说明后台任务继续。重复/不存在的DST时刻要求明确选择，固定时区跨设备保持一致。
- **记忆**：Agent 记住一件事时，会出现"已记住：…"的小标签，可以撤销。所有记忆在设置里统一管理。
- **用量**：助手面板底部用一行小字显示今日用量，比如"今日已用 12%"；使用自带 key 时显示"正在使用你的 API key"。设置 → 助手里的"AI 用量"是一张卡片：今日 tokens 和本月费用各一行数字加一条进度条（进度条只是数字的重复，读屏读数字），下面是预留、重置时间和更新时间。
- **自带 key**（M5，设置 → 助手）：
  - 界面：一个输入框（保存后只显示末 4 位）、"验证并保存"和"删除"两个按钮；key 失效时显示原因。
  - 文案只讲好处：不占每日额度，全站额度用完时也能照常使用（D-034）。
  - 额度用完的提示里，可以附上"使用自己的 API key"的入口。

## 7. 可访问性与键盘

- **对比度与缩放**：D 和 M1b 测 8 色（2026-11-13 起 9 色）× 深浅 × 4 透明度的关键文字/控件，最差玻璃背景也满足正文 4.5:1（D 阶段的脚本和像素级审计结果见第 10.3 节）；200% 字号无裁剪、400% 缩放在 320 CSS px 可完成登录、导航、收发与审批。
- **控件边界**：输入框、开关轨道、复选框、滑块的描边用 `--control-border`（对所有表面不低于 3:1）；分段控件选中的滑块带 1px 描边（白滑块对灰轨道只有 1.1:1）。
- **焦点**：`:focus-visible` 时显示 2px 强调色焦点环，外扩 2px，形状跟随控件（胶囊的环也是胶囊）。可点击区域不小于 28×28px。
- **读屏**
  - 列表用"漫游 tabindex"方式做键盘导航（方向键在项目间移动）。
  - 新消息通过 `aria-live="polite"` 播报。只播报当前打开的会话；短时间内的多条消息合并成一次播报，避免在热闹的频道里刷屏。
  - 虚拟列表为每一项补上 `aria-setsize` 和 `aria-posinset`。
  - 所有图标按钮都要有 `aria-label`。
  - 虚拟列表不能移除当前键盘焦点；提供按页载入的读屏模式和“载入更早消息”按钮，NVDA/VoiceOver 实测阅读顺序。工具菜单同时提供键盘可见入口，弹层关闭后焦点返回触发点；Agent 只播报阶段/完成，不逐 token 播报。
- **快捷键**（Windows 上 ⌘ 对应 Ctrl）：
  - 不使用浏览器保留的组合键，比如 ⌘N、⌘T、⌘W：网页在 Chrome、Edge 的标签页里拦截不到它们（D-052）。
  - 每个快捷键都要在 Chrome、Edge、Safari、Firefox 里实测（V-16）。
  - 所有功能都能在 ⌘K 里找到，快捷键只是捷径。

| 快捷键 | 动作 |
|---|---|
| ⌘K | 命令面板，也用来新建会话、搜索消息、打开设置 |
| ⌘J | 打开或关闭助手面板 |
| ⌥↑ / ⌥↓ | 切换到上一个 / 下一个会话 |
| ⌥⇧↑ / ⌥⇧↓ | 切换到上一个 / 下一个未读会话 |
| ↑（输入框为空时） | 编辑自己的上一条消息 |
| Enter / ⇧Enter | 发送 / 换行 |
| ⌘B / ⌘I / ⌘⇧X（在输入框里） | 加粗 / 斜体 / 删除线：给选中的文字加上或去掉 Markdown 标记 |
| Esc | 关闭弹层，取消编辑或回复 |
| ⌘/ | 快捷键帮助 |
| ⌘, | 设置（浏览器不拦截时有效；否则在 ⌘K 里输入"设置"） |

新建会话用 ⌘K 或侧边栏的"+"按钮。安装为 PWA 后，如果浏览器允许，再给新建会话绑定 ⌘N（M6 实测）。**M6 实现（D-207）**：⌘N 只在安装后的窗口里绑定，打开侧栏的「新建」菜单（窄布局里菜单按钮不在屏幕上，改为打开命令面板），快捷键帮助也只在那里列出它；浏览器会不会把它交给页面，在应用窗口里手工验证（V-16）。安装后的窗口进入 Window Controls Overlay 时，页面在标题栏区域画应用图标和文档标题（前面带未读数），这一条可拖动窗口，各面板从它下面开始。

**站点管理与表单对齐（2026-11-12）**：站点管理页此前还是每条记录一张带阴影的方角卡片、一列二十个输入框，这一轮按其余界面的规则重做——内容居中成一栏（880px）；每个分区的记录收进一张卡片，行与行之间用发丝线（与设置里的分组列表一致）；成员和会话带头像，角色、已封禁、邮箱未验证、已归档、举报状态改用徽标，扫一眼就能找到异常的行；没有记录时用标准空状态，读取时用页面级的加载指示；站点设置的二十项限额按"助手与预算、消息、文件与存储、成员与配额"分组（`fieldset` 加 `legend`），有空间时两列并排，快速与深度两种模式的同类限额左右相对；筛选按钮的文案从重复字段名改为"搜索"（举报分区原先显示的也是"搜索成员或会话"）；弹窗里的下拉框改用 SelectField。两条通用规则：**字段旁的按钮与输入框对齐**——按钮从输入框的顶边起、与输入框等高，而不是对着"标签加输入框"的中线，也不随下方时有时无的提示或报错移动（`.row--field`、`.admin-search`）；**字段的列允许收缩**（`.field` 的列为 `minmax(0, 1fr)`），否则日期时间输入框会按自身的最小宽度把所在的格子撑出去。另修两处：窄屏下消息的悬停工具条原先压住气泡第一行的末尾，现在停在气泡上沿之上，只与气泡的内边距重叠；设置里"提醒与定时消息"在没有"加载更多"时不再留一条空行和分隔线。

**手机宽度的设置面板与助手对话（2026-11-12）**：逐屏复查中英文两种语言、390px 和 320px 两个宽度后改了四处。①**设置行**（`.row`，文字在左、控件在右）：文字至少保有 10em 的行宽，控件太宽、留不出这个宽度时换到文字下面的一行并占满它——分段控件铺满整行，开关和按钮仍靠右。此前手机上"外观模式""玻璃材质"的说明被分段控件挤成两三个字一行，英文下分段控件还伸出卡片；桌面宽度下各行不变。宽度不足 360px 时，带按钮的字段（备注加"生成邀请码"、API key 加"验证并保存"）改为上下排列，分段控件的各段按文字宽度分配并收窄内边距。②**设置分组**（`.group`）的列改为 `minmax(0, 1fr)`：英文下"登录设备"底部两个并排的长按钮放不下，把整个分组连同卡片撑出面板，现在按钮换行。③手机上设置面板顶部的分区是一行横向滚动的标签：还有内容的一端淡出（遮罩由这一行自己的滚动位置驱动，面板是半透明的，没有可以盖在标签上的底色；不支持滚动驱动动画的浏览器没有淡出），细滚动条照常保留（窄的桌面窗口里鼠标靠它滚到最后几个标签，淡出只是补充提示），当前分区的标签自动滚到可见位置。④**助手对话**：工具栏副标题从"1 位成员"改为"助手对话"；详情面板原先把它的类型写成"私信"，现在写"助手对话"，并且不再列出只有本人一行、标着"群主"的成员列表（docs/01 第 4.4 节：助手对话的成员只有本人）。

**界面重构为悬浮玻璃（2026-11-13，分支 `feat/liquid-glass-redesign`）**：整套界面按第 1–5 节的新要点重做。①**布局**：三块浮在壁纸上的面板改为"窗口即内容"——会话铺满窗口，侧栏与 Inspector 是浮在上面的玻璃面板，工具栏拆成标题胶囊（同时是"成员与详情"的按钮，原来单独的成员图标取消）和工具胶囊，输入栏是一枚附件圆片加一枚胶囊并浮在会话之上，内容在两处向底色淡出。②**材质与令牌**：新增只放图标的 `.glass-clear`（下限由对比度脚本按 3:1 反推）；深色底加深到 #0E0E10；强调色与状态色的深色实底改为白字可读的深一档；圆角整体放大并同心；阴影分三档；`corner-shape: squircle` 只留给频道方块。③**控件**：按钮、图标按钮、分段、搜索框成为胶囊；开关、滑块、复选框、菜单、对话框、Toast、Tooltip 全部重画；`<select>` 在支持 `appearance: base-select` 的浏览器里弹出玻璃菜单；确认框改为居中的警示样式；Toast 移到窗口顶部。④**聊天**：纯图片消息和一到三个 emoji 的消息不套气泡；悬停显示"时:分"；助手流式回复时气泡边缘有转动的光带（此前规范里有、实现里没有）；发送者名字旁补上"机器人"标签（同上）；头像可点开资料卡并发起私信；emoji 面板分组并记住最近使用；⌘B / ⌘I / ⌘⇧X 格式快捷键；文件可以拖到会话任意位置；侧栏显示未发送的草稿；侧栏加载时显示骨架行。⑤**设置**：左侧导航成为面板里的面板，每个分区的图标有自己的色块；外观预览按新布局重画。Storybook 的截图基线需要全部重新生成（`bun run test:visual -- --update-snapshots=all`）。

**浅色主题改为米白（2026-11-13，同一分支）**：维护者试用后觉得浅色主题的纯白底配冷灰偏冷、不耐看。浅色的窗口底改为米白 #FAF7F1，壁纸底 #F3EFE7，弹层与卡片 #FFFDF9，别人的气泡 #EEE9DF；文字的三档灰、分隔线、控件底色和描边、代码块底色、玻璃底色、阴影与发丝线都换成同一方向的暖色（第 4.1 节的表已更新），每个值与它取代的冷灰亮度相同或更深，对比度的余量不变。壁纸的光在浅色主题里降到 24%，下方那一块固定为暖杏色（第 2 节）；登录页的光为 40% / 58%，同时修正了一处错误：原先用 `light-dark()` 写百分比是无效声明，登录页实际上没有光。深色主题不变。

**强调色改为一组颜料（默认墨水蓝，新增青），气泡尾巴重画（2026-11-13，同一分支）**：维护者试用后指出两点。①默认的蓝在深浅两种主题下都刺眼。先把蓝调成低色度的墨水蓝，维护者认为好了很多，并要求调研后换别的颜色多试几种。调研结论：Radix Colors 建议中性色与强调色取相近色相（暖灰配黄、琥珀、橙、棕，冷灰才配蓝），冷蓝压在米白上本身就不搭；Material Design 指出深色底上的高饱和色会产生视觉振动、让眼睛疲劳，应使用去饱和的颜色；微信、WhatsApp、Telegram 自己的气泡都是淡彩或低饱和的深色（WhatsApp 深色约 #204F46，Telegram 深色约 #2B5278），没有一家用满色度的实底；Perplexity 用纸白配青绿；青绿山水（《千里江山图》）是石青、石绿画在暖色绢上。据此九种强调色按同一条规则重新生成（第 4.1 节），其中青是新增的；维护者把九种在界面里逐一看过后，默认仍定为蓝（墨水蓝）。"提示"状态色、设置里各分区图标的色块（色度 0.17 降到 0.14）和强调色实底下的彩色投影一并收敛；对比度脚本 2898 组全部通过。各设备保持原来的选择，只是每种颜色都变柔和了。②收到的消息里，头像的右缘被气泡盖住一条：尾巴原先是"一块气泡色"加"一块底色"挖出来的，底色那块宽 10px，而头像只在 8px 外。尾巴改为单独一片、用 `clip-path` 裁出形状（第 4.2 节），同时消除了自己气泡尾巴根部与渐变不一致的一小块色差。③消息旁的时刻改为淡入、离开时立即消失：菜单刚盖上来时不再有半透明的文字留在后面（无障碍检查曾在这一瞬间扫到它）。
