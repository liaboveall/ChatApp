## 八项反馈与结果

| 反馈 | 实现后的行为 | 主要位置 |
|---|---|---|
| 1. 选择 @ 后输入框显示内部标记 | 输入框显示 `@显示名`，草稿与发送仍保留选择的精确用户 ID。移动光标、同名成员、空格/emoji、局部编辑和跨提及粘贴不会按名字猜收件人；修改提及名字会退回普通文字 | `features/composer/mention-draft.ts`、`composer.tsx` |
| 2. 英文助手侧栏内容截断 | 控件允许换行，网格/分段按钮/历史选择器有正确的最小宽度；侧栏回答独立滚动，提示输入和发送按钮保留空间 | `styles/agent.css`、`styles/shell.css`、`features/agent/panel.tsx` |
| 3. 蓝色气泡中的 @ 看不清 | 发出气泡里的提及使用气泡的高对比文字和内嵌底色，并保留下划线 | `styles/attachments.css` |
| 4. 头像裁剪只能用滑块 | 可以直接用鼠标或触控拖动图片，缩放后仍按实际图像坐标裁剪并限制边界；保留滑块和方向键微调，Shift 加大步长 | `features/attachments/avatar-editor.tsx` |
| 5. AI 提示与聊天重叠 | 消息列表与底部输入区域采用纵向布局；提示占用自己的空间，时间线不延伸到输入区域下面。私有助手页与群聊均适用 | `styles/chat.css`、`features/conversations/conversation-screen.tsx` |
| 6. 插入助手回复是原始 Markdown 且带 seq | 插入后先显示 Markdown 预览，可切换“编辑内容”；只有手动发送才进入群聊。普通正文里的内部引用被清理 | `features/agent/panel.tsx`、`features/composer/composer.tsx`、`lib/sync/drafts.ts` |
| 7. 侧栏不能新建/删除历史，体验粗糙 | 增加新建、历史切换、重命名、删除确认、读取更早消息和说话人标识；每个保存的会话有自己的草稿、模式和读取范围。快捷按钮保留未发送草稿，主输入框斜杠命令继续当前选中的历史 | `features/agent/panel.tsx`、`controls.tsx`、`store.ts`、服务端 `domain/agent-runs.ts` |
| 8. 群聊 @AI 回答含 seq | 模型提示要求以发送者/时间描述来源；最终消息正文和旧消息的显示/插入统一清理内部 seq、messageId 和 UUID 引用。运行步骤和工具来源仍完整保留供调用者查看 | `packages/contracts/src/assistant-text.ts`、`agent/prompts/system.ts`、`domain/agent-runs.ts`、`features/timeline/message-row.tsx` |

`assistantText` 保留代码块、行内代码、Markdown 链接和有效 JSON；普通用户消息不经过该清理。增量流持久化保持原始偏移与版本，完成时再清理最终正文。没有批量改写历史消息、删除证据或改变工具权限。单纯输入同名 `@名字` 仍是普通文字；只有从候选列表选择才产生实际提及。

## 会话与迁移

`POST /api/agent/runs` 增加可选 `newConversation`。显式新建不复用旧面板，显式 `conversationId` 继续该所有者、该上下文的历史；不传两者则选最近活动的面板。新建与已有 ID 不可同时指定，私有 Agent 主会话不能使用该标志。所有者与上下文鉴权、世代隔离、幂等和删除流程沿用原领域边界。

0011 将 `(owner_id, panel_for_conversation_id)` 的唯一索引替换为普通部分索引，允许同一用户在同一群/频道保存多段独立私有对话。开发库和测试库迁移成功，`db:check` 通过；没有重置开发数据。后端集成覆盖新建、默认复用、显式继续、跨用户不可见、删除后其他历史保留及输入冲突。
