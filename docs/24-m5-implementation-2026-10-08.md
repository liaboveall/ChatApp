## 2. M5a 交付

- `agent_approvals` 保存原始与修改后的审批参数；待批时停止执行，24 小时到期，批准/拒绝与恢复序号、epoch、后台工作同事务。到期拒绝先提交状态，再在事务外返回冲突，避免回滚掉过期记录。
- `agent_effects` 与业务写入在同一 Postgres 事务；效果键、确定性 `clientId`、租约与终态重放共同保证去重。发送、预约发送、建群、邀请成员均需本人审批；提醒只影响本人，按规格无需审批。
- 调度任务携带受限子委托、批准参数与来源设备；普通退出、撤销设备、安全注销全部、改密及来源失效分别按真值表处理。自动发送不推进已读；取消与到点发送串行化，任务上限、365 天预约上限及 24 小时截止保持原门槛。UTC、时区和 offset 冻结，DST 重复时刻必须由本人选择。
- 自带 DeepSeek key 经固定 HTTPS endpoint 验证，AES-256-GCM 加密存储。运行创建时固定来源与 revision，替换/删除使旧上下文失效；切换来源创建空白 key 段，权威 `stateVersion/historyFromSeq` 阻止迟到响应恢复旧界面。scope 改变更新模型上下文，仍可按权限浏览同 key 历史。
- BYOK 私有标签和完整来源清单传递到历史、附件、工具结果、摘要及记忆；站点运行过滤私有来源，管理员只获得私有运行元数据。用量按来源统计，密钥不进入响应或日志。
- 设置界面包含自带 key、额度、未来任务与记忆管理；审批卡可修改、批准、拒绝，完成效果后不提供会重放操作的重新生成。本人新增记忆可撤销。

D-197 说明批准的私有邀请效果如何刷新自己的成员版本，D-198 说明工具 JSON schema 与上下文在原输入上限内的表示；都不放宽授权或预算。

## 3. M5b 交付

- 记忆最多 200 条，每条最多 500 个 Unicode 字符，限本人管理。手工默认 `byok_private`，只有显式同意才开放站点使用；AI 私有派生记忆不能直接提升为站点可用。隐私撤销带 CAS 版本检查，立即删除向量并使受影响运行、审批和摘要失效。
- `remember/forget/recall_memories` 和语义消息检索已接入正式工具循环。只在 `all_accessible` 提供个人记忆；仅本轮用户明确记忆意图可免审批，否定、引号及引用中的指令不当授权。最多注入 5 条相关记忆，并用 untrusted 块包裹。
- 消息和记忆向量带 content/model version；业务事务只排 identifier-only intent。推理在锁外执行，发布前重锁核对当前内容、撤回、删除、隐私及模型版本，迟到结果不写回。消息编辑重算，撤回和记忆删除立即移除向量。
- 512/1024 维索引分开，generation 可 staging/active/retired；新模型回填时保留旧 active。历史回填按 durable UUID cursor 分批最多 100 条，延迟批工作，实时工作更高优先级；不同模型队列不会消费错误维度工作或空耗重试。
- 混合检索用 RRF 合并关键词/余弦结果；语义候选在 SQL 内联表检查当前成员、加入边界、隐藏、删除/撤回、共享成员共同可见性、当前内容版本和私有标签。向量没有单独授予读取权限。
- 滚动摘要采用带来源时间/发送者的原文摘录，覆盖最近 30 条之前最多 48 条同 epoch 消息，避免新增生成摘要带来事实编造。摘要保存完整传递来源、版本、key、隐私与 through-seq；失权/编辑立即失效，30 天截止，定期物理清除过期正文和 manifest。模型输入预览有截断标记，可继续用读取工具取得原文。
- API 不加载 ONNX。Bun 子进程通过私有 Unix socket 提供离线本地 embedding，目录 0700、socket 0600；子进程使用凭据空白白名单及 `--no-env-file`，没有 DB、S3、SMTP、AI key。每次请求有大小、并发和时限约束，1 GiB RSS watchdog，在超限时停止，不自动改用远端向量服务。
- 已固定 transformers 4.3.1、模型 revision、q8 权重、维度和 pooling；384 Unicode 字符分块覆盖完整内容，再平均/归一化。模型在线准备是显式运维命令，运行时只读校验后的缓存。
