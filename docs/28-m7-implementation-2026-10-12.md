## 已实现与边界

- 独立 R2 客户端：私有签名请求、不可覆盖记录、读回 hash、ETag/CAS、分页完整列举、超时与脱敏错误；严格区分 Garage、journal 和 backup 测试目标。
- AES-256-GCM 加密 journal：独立密钥/版本、认证 head、seq/previous hash、稳定 operation ID、重复写与未知结果对账、writer epoch。仅 head 可达链有效；缺 head、缺密钥、断链拒绝恢复。
- 数据库 `prepared → journaled → applied`、目标冻结、连续 applied 水位。消息撤回/管理删除、记忆、私有 Agent 会话、上传取消/孤儿附件、账号注销及固定规则的内容到期清理已接入。Agent forget 效果账本记录 pending，完成前不冒充删除成功。
- 注销使用当前密码确认；同事务匿名化、撤销登录/委托、删除记忆/BYOK/推送与私有 Agent 内容、取消任务、退出群组和转让所有权，保留匿名公开消息/附件及 DM 关系。账号失效后仅本次状态 GET 可用十分钟的 HttpOnly/SameSite=Strict 路径限定回执查询；其他有效登录不能使用它绕过账号隔离。客户端处理登录世代、操作 ID/版本及注销后确认，未确认不显示成功。
- 广泛删除（账号、整个私有会话、retention）与未完成意图互斥准备，冲突返回 `409/deletion_busy`，避免来源失效清理被另一个目标冻结永久阻塞。session 到期/普通退出可收窄权限，新增凭据仍被冻结。
- 加密 checkpoint：核验远端 restic 完整快照目录、逐份数据库/对象/恢复材料 hash，取所有快照锚点与连续 applied 水位的安全边界；先读回 checkpoint 并 CAS 认证 head，才清理旧记录。超龄快照延长对应链；缺目录/锚点/密钥拒绝裁剪。已测断链、错误锚点、未知 CAS 结果、GC 中断后续跑和旧操作重试边界。长时间核验目录时不占用删除 writer；备份目录变化受独立锁约束。
- 一致备份 domain：等待在途对象删除、租约屏障、共享 REPEATABLE READ 快照、pg_dump/活对象清单/应用基线 SHA/迁移 hash/applied 水位同读、对象全量校验、restic 异地读回后才 succeeded。备份使用拥有者连接；API 仍无迁移历史权限。
- 对象存储适配器的普通删除、上传失败清理及后台物理删除均检查屏障；去除重复嵌套屏障，单连接池也能延后并恢复清理。恢复前失效旧认证及委托、旧备份租约，取消有歧义外发；重放绑定原 manifest，事务中断可从已应用水位续跑，损坏后缀在内容变更前拒绝。重放后重新执行当前到期规则，保留仍使用的头像/已发送文件；持久隔离标记阻断 API/worker，漏填 `RESTORE_MODE` 也不能开启恢复数据。
- 迁移 0017–0022 已前向应用到开发与测试库；不修改已应用的 SQL。0019 在测试库暴露函数数组签名问题后，用 0020 前向修复；0021/0022 补隔离时的凭据撤销及正常 session 失效。配置依旧 `DELETION_JOURNAL_ENABLED=false`，没有初始化或启用普通开发 writer。
