# 01 产品规格

> 本文件以产品行为为准。数据约束见 [04](04-data-model.md)，接口见 [05](05-api-and-realtime.md)，Agent 细节见 [06](06-agent.md)。
> 所有可调数值集中在第 7 节。代码里不要硬编码，统一从配置读取。

## 1. 定位

- **邀请制的实时聊天社区**：只有持有邀请码的人能注册，社区内的人可以建频道、拉群、私信。
- **内置 Agent**：它可以读聊天记录并帮你总结、搜索、翻译、起草，经你批准后还能代你执行操作。既可以用站点提供的额度，也可以填写自己的 DeepSeek API key。
- **桌面优先**：以 ≥ 1280px 为主要桌面布局，1024px 起为双栏。桌面缩放后的 320 CSS px 单栏重排在本版支持；手机专用手势和布局优化仍在 v1.1。
- **中文优先**：默认简体中文，另外提供英文。
- **设计容量**：注册用户 1000 人以内，同时在线 200 人左右（约 500 个 WebSocket 连接）。超出这个规模，再考虑多实例和更重的运维配套（D-052）。

## 2. 角色

| 角色 | 说明 |
|---|---|
| 访客 | 未登录，只能访问登录、注册（需邀请码）、找回密码、隐私说明 |
| 成员 | 已注册、已验证邮箱的普通用户 |
| 站点管理员 | 可管理用户、邀请、频道、举报、审计日志和 AI 预算，可查看使用站点 key 的 Agent 运行内容（见第 5 节）。第一个站点管理员用命令行创建 |
| 会话内角色 | 群主 `owner` / 管理员 `admin` / 成员 `member`，只对频道和群组有意义 |
| Agent | 机器人用户，不能登录，只能通过 run 发消息；不是任何会话的成员 |

## 3. 功能范围

标记说明：**M1–M7** 表示在哪个里程碑实现，都属于上线版；**v1.1** 表示上线后做；**✗** 表示明确不做。里程碑的细分（M1a、M1b 等）见 [11](11-roadmap.md)。

### 3.1 账号与邀请
- M1：用邀请码注册（邮箱、用户名、显示名、密码）、邮箱验证（可以重发验证邮件）、登录、退出、找回密码、Passkey 注册与登录
- M1：设备与会话管理（查看并注销其他设备；被注销的设备立即断开实时连接）
- M1：生成、查看、撤销注册邀请码（设置页里的简单界面）；查看用自己的邀请码注册、但还没验证邮箱的账号，可以撤销
- M1：站点管理员用命令行手动标记邮箱已验证，作为邮件送不到时的兜底；M7 起后台也可以操作
- M2：个人资料（显示名、头像、简介、时区），用户名可以修改（有冷却期）
- M7：注销账号
- v1.1：两步验证（TOTP）、屏蔽用户
- ✗：第三方登录（邀请制下意义不大）

### 3.2 会话
- M2：频道（创建、发现、加入、退出）、群组（创建、拉人、群邀请链接）、私信（与任何成员发起）
- M2：会话内角色与管理：改名、简介、头像、踢人、封禁（移出并禁止再加入）、禁言、转让群主、归档与恢复
- M2：会话个人设置：置顶、免打扰、隐藏私信
- M2：新成员只能看到加入之后的消息
- M4：Agent 会话（可以有多个，可以删除）
- v1.1：话题线程（thread）、入群审批

### 3.3 消息
- M2：文本（Markdown 子集）、回复引用、编辑（24 小时内）、撤回（2 分钟内）、仅自己删除、管理员删除、系统消息
- M3：附件（图片、视频、音频、文件），支持拖拽、粘贴、上传进度；emoji 选择器；@提及（自动补全、高亮）
- M4：消息关键词搜索（在 ⌘K 中使用，不消耗 AI 额度）
- v1.1：表情回应、置顶消息、收藏、转发、链接预览、语音消息、高级搜索（按人、时间、会话筛选的独立界面）
- ✗：音视频通话、端到端加密、阅后即焚

### 3.4 实时
- M2：
  - 即时送达、正在输入；
  - 在线状态（在线、离开、离线、最后在线时间）；
  - 已读位置与未读数；
  - 多标签页和多设备同步；
  - 断线补发，以及漏收事件后自动补齐；
  - 乐观发送与失败重试。
- v1.1：私信已读回执。

### 3.5 通知（M6）
- **浏览器推送**：私信、@提及、回复我的、Agent 等待审批。
- **站内通知中心**：@我、回复我的、Agent 等待我审批、提醒到点；站点管理员另外还会收到预算提醒和新举报。
- **会话通知级别**：全部 / 仅 @我 / 关闭，以及限时免打扰。
- **未读数与安装**：标题栏和应用角标显示未读数；桌面 PWA 可以安装成独立窗口。
- **v1.1**：邮件摘要。

### 3.6 Agent
- **M4**：
  - 入口：Agent 会话、群内 @Agent、侧边助手面板、⌘K 命令面板和斜杠命令；
  - 只读能力：总结、搜索、翻译、起草、看图；
  - 流式输出、停止、重新生成（替换原回复）；
  - 用量配额。
- **M5**：
  - 需审批的操作：代发消息、定时消息、建群、拉人；
  - 只影响自己的操作（提醒、记忆）不需要审批，但界面上看得到，也可以撤销；
  - 长期记忆和语义搜索；
  - 使用自己的 DeepSeek API key（自带 key）。
- **v1.1 起**：联网（网页搜索、读取链接）、MCP 外部工具、用户自建 Agent。
- 详见 [06-agent.md](06-agent.md)。

### 3.7 管理（M7）
- **管理后台**：
  - 用户：封禁、调整邀请名额和各项限额、调整角色、手动标记邮箱已验证；
  - 邀请；
  - 频道与群组：归档、恢复、封禁名单；
  - 举报处理、审计日志；
  - AI 用量与预算、AI 运行记录（见第 5 节）。
- **举报消息**：所有成员可用。
- **隐私说明页**：见第 4.11 节。
- **v1.1**：敏感词过滤。

## 4. 行为规则

### 4.1 注册与登录
- **注册链接**：格式是 `/register#invite=<code>`。邀请码放在 `#` 后面，不会发到服务器，所以不会出现在访问日志里。也可以在注册页手动输入邀请码。
- **校验邀请码**：注册前先校验，无效、过期或已用完都给出明确提示。
- **必填项**：邮箱、用户名、显示名、密码。
- **密码**：至少 10 位，并拒绝常见弱密码。
- **邮箱验证**：必须验证邮箱才能登录，验证邮件可以重发。本地开发时，验证邮件在 Mailpit 里查看。
- **占用名额**：注册有稳定登记标识，名额预占、账号创建、登记确认和邮箱验证按 D-059 的状态机恢复；登记确认与邮箱验证同时满足才可登录。创建后崩溃不释放已经关联账号的名额。
- **未验证的账号**：7 天内没有验证邮箱的账号会被自动删除，占用的邀请名额、用户名和邮箱随之释放。邀请人也可以提前撤销，比如对方把邮箱填错了。
- 注册成功后，记录"谁邀请了谁"。
- **登录**：用邮箱 + 密码，或 Passkey。登录会话 30 天滚动过期。
- **找回密码**：通过邮件链接，链接 1 小时后失效。
- **修改密码与注销**：
  - 修改密码后，其他设备的登录会话全部注销；通过邮件重置密码后，所有登录会话都注销。
  - 注销设备、修改或重置密码、账号被封禁时，相关设备的实时连接在几秒内断开。

### 4.2 邀请
**注册邀请码**
- 站点管理员可以无限生成。
- 普通成员共有 5 个"成功邀请"名额：生成邀请码不消耗名额；有人用它注册时占用一个；如果对应账号被清理或撤销，名额退回。管理员可以为单个用户调整名额。
- 默认有效期 7 天、只能用 1 次，创建时可以调整。可以随时撤销。
- 数据库只存邀请码的哈希；明文只在创建时显示一次。

**群邀请链接**
- 链接格式是 `/join#<code>`，码同样在 `#` 后面。
- 只对已注册用户有效，不能用来注册账号。
- 默认有效期 7 天、次数不限，可以设置上限，可以撤销。
- 谁能创建由群设置 `whoCanInvite` 决定：`all_members`（默认）或 `admins_only`。
- 创建者退出或被移出群组时，他创建的链接自动失效。群设置为 `admins_only` 时，创建者被取消管理员身份，链接同样失效。
- 被封禁的人不能通过链接加入。

### 4.3 用户资料
- **用户名**
  - 规则：3–20 位，小写字母、数字、下划线，全站唯一，用于 @提及。
  - 每 30 天可以改一次；旧用户名保留 30 天，不能被别人注册。
  - 保留名不能注册，比如 `admin`、`system`、`root`、`support`、`assistant`、`agent`，以及 Agent 的用户名。
- **显示名**
  - 1–32 个字符，可以重复，支持中文和 emoji。
  - 不能使用保留名，比如"助手""系统""管理员"，以及 Agent 的显示名。比较前先做 NFKC 规范化，并忽略大小写和空白。
- **头像**：只能上传图片，服务端裁成正方形并生成多种尺寸。
- **时区**：默认跟随浏览器，也可以在设置里固定。用于 Agent 理解"明天上午"这类时间，以及决定提醒何时触发。
- **在线状态**：社区成员互相可见。v1.1 再加"隐藏在线状态"的选项。

### 4.4 会话规则

| | 频道 | 群组 | 私信 | Agent 会话 |
|---|---|---|---|---|
| 谁能创建 | 任何成员 | 任何成员 | 任何成员（和对方） | 本人 |
| 谁能看到 | 全站成员（可在"发现"里搜到） | 仅成员 | 仅双方 | 仅本人 |
| 如何加入 | 自己加入 | 被拉入，或用群邀请链接 | 自动 | — |
| 新成员能否看到加入前的消息 | 不能 | 不能 | — | — |
| 名称 | 必填，全站唯一（NFKC 规范化后比较，忽略大小写） | 必填，可以重复 | 无（显示对方名字） | 自动生成，可以修改 |
| 成员上限 | 5000 | 500 | 2 | 1（本人，机器人不算成员） |
| 允许 @Agent | 默认开启，群主可关闭 | 同左 | 不允许（请用 Agent 会话） | — |
| 能否删除 | 不能，只能归档 | 不能，只能归档 | 不能，只能隐藏 | 能 |

- **加入前的历史**（D-035）
  - 新成员只能看到自己加入之后的消息；退出或被移出后再加入，按新成员处理。
  - 时间线顶部显示"你于某时加入，之前的消息不可见"。
  - 如果一条回复引用了加入前的消息，引用条显示"原消息不可见"。
  - 搜索和 Agent 同样看不到加入前的消息；共享 Agent 自动读取只取所有当前成员共同可见的历史，成员变化时旧运行停止。用户主动粘贴或转述作为新消息处理，系统无法阻止人工转述。
- **私信**：同一对用户只有一个私信会话。私信不能"退出"，只能隐藏；对方发来新消息时自动取消隐藏。
- **退出与转让**：还有其他成员时，群主必须先转让；只有群主一人时，可直接退出并自动归档，保留其归档管理权。恢复时重新加入，历史水位按重新加入时计算（04 第 2 节）。
- **移出与封禁**：管理员可以"移出"成员，也可以"移出并封禁"。被封禁的人无法通过频道发现、群邀请链接或被拉入的方式重新加入，直到解除封禁。
- **归档**
  - 会话变为只读，并从成员的列表中移除。
  - 群主和站点管理员可以在"已归档"里找到并恢复它。
  - 恢复频道时，如果名称已被新频道占用，需要先改名。
- **删除 Agent 会话**：取消活动 run/审批/未来任务，删除消息与运行内容，只留无正文用量元数据；附件立即不可读，物理删除按第 4.11 节执行。

### 4.5 消息规则

**正文**
- 用户消息最多 5000 Unicode 码点，Agent 消息最多 20000；达到上限停止生成并显示截断，不把供应商的 token 上限等同于字符上限。
- Markdown 支持以下子集：
  - 支持：粗体、斜体、删除线、行内代码、代码块（带语言高亮）、链接、有序和无序列表、引用。链接可以自动识别，遇到中日韩文字、全角标点或空白时结束。
  - 不支持：标题（按普通段落显示）、图片（图片只能通过附件发送）、原始 HTML（一律当文本显示）、数学公式、图表语法。
  - 链接只允许 `http`、`https`、`mailto` 三种协议，并在新窗口打开。

**@提及**
- 在正文中存为 `<@user:UUID>`，显示时再换成当前的显示名，所以对方改名后，历史消息里显示的也是新名字。
- `@Agent` 同理，会触发一次 Agent 运行（见 06）。
- 编辑时新增的 @提及会高亮，但不产生通知，也不会触发 Agent。
- Agent 消息里的 @提及只做显示，不产生通知。
- v1.1：`@所有人`。

**回复**
- 引用一条消息，显示发送者和摘要（前 100 字）。
- 被引用的消息如果已撤回或删除，显示"原消息已撤回"或"原消息已删除"；如果是自己加入之前的消息，显示"原消息不可见"。

**编辑**
- 只有发送者能编辑，时限 24 小时，编辑后显示"已编辑"。不保留编辑历史。

**撤回**
- 只有发送者能撤回，时限 2 分钟。服务端判断时限时额外留 5 秒宽限，用来抵消网络延迟。
- 撤回后所有人看到“某某撤回了一条消息”，正文在线清空、附件立即不可访问；文件目标 1 小时内物理删除，最长 24 小时，副本及备份见第 4.11 节。

**删除**
- 仅自己删除：任何成员随时都可以把消息从**自己的视图**中移除，别人不受影响。发送者如果想让所有人都看不到，在撤回时限内应该用撤回；超过时限后，就只能仅自己删除。
- 管理员删除：会话群主或管理员、站点管理员可以删除任何消息。所有人看到“此消息已被管理员删除”，正文在线清空、附件立即不可访问，物理删除期限同撤回，并写入无正文审计。

**系统消息**
- 在群组和私信中产生：成员加入、离开、被移出、会话改名、群主转让。
- 频道里成员加入和离开**不**产生系统消息，只反映在成员列表中，以免刷屏。

**显示规则**
- 同一发送者 3 分钟内的连续消息合并为一组，只在第一条显示头像和名字。
- 两条消息间隔超过 1 小时，插入时间分隔条。
- 未读消息上方显示"以下为新消息"分隔条。
- 离开底部阅读历史时，出现"回到最新"按钮，并显示期间的新消息数。

**发送体验**
- 发送时立即显示在界面上，状态为"发送中"。
- 失败时显示红色感叹号，可以重试或删除。
- 重试不会产生重复消息，靠幂等键保证。
- 用输入法打字时，回车用来确认候选词；组字期间按回车不会发送（D-050）。

### 4.6 附件

| 类型 | 识别方式 | 大小上限 | 展示方式 |
|---|---|---|---|
| 图片 | 按文件内容判断：jpeg、png、gif、webp、avif | 20 MB | 缩略图，点开大图预览；先按拍摄方向旋转，再去除 EXIF 信息 |
| 视频 | mp4、webm（mov 在 Safari 可播放） | 100 MB | 内嵌播放器；不转码，但会重新封装以去除位置等元数据 |
| 音频 | mp3、m4a、ogg、wav | 100 MB | 内嵌播放器 |
| 其他文件（含 svg、html、heic 等） | 其余所有类型 | 100 MB | 文件卡片，只能下载 |

- **数量与空间**：每条消息最多 10 个附件；每人默认上限 5 GB（处理后主文件），不是预留存储承诺。全站实际容量不足也会拒绝新上传；衍生图和备份计入全站容量。
- **图片处理**：
  - 先按方向信息把图片转正，再重新编码原图以去除 EXIF（避免泄露拍摄地点）；
  - 另外生成缩略图（最长边 480px）、预览图（最长边 1600px）和 thumbhash 模糊占位图；
  - GIF 在帧数/累计像素限制内保留动画，只用第一帧生成缩略图；超过 40MP 静态图、200 帧或累计 100MP 动画等资源限制时明确拒绝，不无限解码。
- **视频处理**：
  - 重新封装（不转码），去掉位置等元数据；处理失败的视频改为文件卡片，只能下载。
  - 浏览器无法播放的视频（比如部分 HEVC 编码的 mov），界面自动改为文件卡片，仍然可以下载。
- **下载权限**：
  - 消息里的附件：只有能看到这条消息的人能下载；还没发出去时，只有上传者能下载。
  - 用户头像：所有登录成员都能看。
  - 会话头像：频道的头像全站成员都能看；群组和私信的头像只有成员能看。
- **清理**：上传后 24 小时内没有发出去的附件会被自动清理。
- **v1.1**：视频封面帧、HEIC 转换。

### 4.7 实时

**正在输入**
- 输入时最多每 3 秒通知一次；5 秒内没有新通知就自动消失。
- 显示为："某某正在输入…"，多人时显示"某某等 3 人正在输入…"。

**在线状态**
- 在线：至少有一个连接，且最近 5 分钟有操作。
- 离开：有连接，但 5 分钟无操作，或页面在后台。
- 离线：没有连接，显示"最后在线 X 分钟前"。最后在线时间取用户最后一个连接断开的时刻。
- 只订阅当前可见用户的在线状态，比如列表和成员面板里的人。

**已读与未读**
- 打开会话并滚动到底部时，把已读位置推进到最新消息的 seq。自己发出的消息自动算已读。
- 加入会话时，已读位置设为当时最新的消息，所以未读数从加入之后开始算。
- 未读数 = 会话最新 seq − 我的已读 seq，超过 99 显示"99+"。
- 已读位置在多设备之间同步。

**断线补发与自动补齐**
- 断线重连后，按 `change_seq` 补齐漏掉的新消息、编辑和撤回，不重复、不遗漏。
- 连接不断时也每 30 秒轻量对账；通过有固定上界的同步日志补齐，正常依赖下最后一个丢事件目标 35 秒内补上（D-056）。离线/依赖故障显示未同步，不假装送达。
- "仅自己删除"同样会同步到离线后重新上线的设备。

### 4.8 通知（M6）

| 事件 | all | mentions | none / 免打扰 |
|---|---|---|---|
| 私信、频道/群普通用户新消息 | 推送（本人发出的除外） | 不推送 | 不推送 |
| @我、回复我的用户消息 | 推送 | 推送 | 不推送 |
| Agent 等待本人审批、个人提醒 | 按全局助手通知开关；会话级免打扰同时生效 | 同左 | 来源会话关闭则不推送，站内仍可查 |
| 系统消息、编辑、Agent 输出/@提及 | 不因这些动作推送 | 不推送 | 不推送 |

- 新加入群/频道默认 notify_level=mentions，私信默认 all；用户可改。all 的普通消息只发浏览器提示，不为每条普通消息创建站内通知。全局推送关闭优先于全部规则。
- 当前用户正在前台查看该会话时不推送；focus 是尽力抑制，不保证绝无重复通知。站内通知中心仍保存 @我、回复、审批、提醒、管理员预算/举报事件，保留 90 天。
- 默认推送只显示“你有新消息”；用户可明确开启最多 80 字摘要。任务仅保存资源 id，发送时重新检查 session、成员/历史水位、消息撤回状态、偏好和端点绑定。已投递到外部推送服务的通知可能无法撤回。
- 端点仅允许验证过的浏览器推送服务，注册和发送都实施 SSRF 防护（07 SEC-23）；注销设备删除订阅。A 退出 B 登录必须重新订阅，不沿用 A 的 endpoint 绑定。
- 中国大陆的 Chrome/Edge/Safari 可达性以 V-10 的设备、浏览器版本、网络和日期记录为准，不从厂商名字推断一定可达。站内通知和标题栏未读数是基础保障。

- M4：在 ⌘K 中按关键词搜索消息，只搜我能看到的消息，不消耗 AI 额度。Agent 也使用同一套搜索。

### 4.10 设置
- **外观**：主题（浅色 / 深色 / 跟随系统）、强调色、透明度（清透 / 标准 / 着色 / 不透明）、减少动态效果、字号。
- **通知**（M6）：总开关、推送时是否显示内容、各会话的通知级别。
- **账号**：邮箱、密码、Passkey、登录设备、时区、注销账号（M7）。
- **邀请**：我的邀请码、剩余名额、还没验证邮箱的注册（可以撤销）。
- **Agent**：用量、长期记忆（查看、删除）、默认模式（快速 / 深度）、自带 API key（M5）。

### 4.11 隐私与数据说明

隐私说明页在 M7 上线前完成，注册页和设置页都有入口。内容必须如实写明以下各项，并随实际行为同步更新（D-048）：

| 事项 | 说明 |
|---|---|
| 站点管理员能看到什么 | 不能读取自己不在其中的群组、私信和 Agent 会话的消息，只有两个例外：①处理举报时，看到被举报的消息及前后各 5 条；②使用站点提供的 AI 额度时，Agent 运行的完整内容（请求、读取到的消息、工具调用和结果、回复）在保留期内可以查看。每次查看都记入审计日志 |
| 自带 key 的运行 | 使用自己的 API key 时，管理员只能看到用量、状态等统计信息，看不到内容 |
| 发给 AI 服务的数据 | @助手 或使用助手时，相关的消息和图片会发送给 AI 服务商（目前是 DeepSeek）处理 |
| 撤回和删除 | 在线正文、提及和向量立即清空，附件立即不可读；文件物理删除目标 1 小时、最长 24 小时，失败会告警重试。既有 Agent 运行副本在创建后 30 天内清除且不再用于续跑；备份副本最长 28 天。已交给模型服务商、外部推送服务、用户下载或失联设备的副本不保证远程收回 |
| 保留期 | Agent 运行内容 30 天；通知 90 天；未验证的账号 7 天；未发送的附件 24 小时 |
| 注销账号 | 删除个人资料、登录方式、记忆、自带 key、推送订阅、通知和私有 Agent 会话及运行内容；取消活动运行、审批和未来提醒/定时消息。发过的普通聊天消息保留，发送者显示为“已注销用户” |
| 范围切换与本地数据 | Agent 范围切换会新开上下文段；浏览器数据按账号与登录世代隔离。离线冷启动仅显示外壳，已打开标签页可读已载入内容；消息/草稿最多 7 天、待发纯文本 24 小时，联网先验证身份再发送 |
| 管理员与运维边界 | 上述限制约束应用后台角色。本项目不提供端到端加密，能控制主机、数据库和服务端解密密钥的运维人员具有更高技术访问能力 |

- 开启了助手的会话，会在会话详情里显示一行提示："@助手 时，最近的消息会发送给 AI 服务处理。"（M4）
- 鼓励使用自带 key 的文案只讲好处：不占每日额度，全站额度用完时照常可用（D-034）。
