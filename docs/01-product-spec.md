# 01 产品规格

> 本文件以产品行为为准。数据约束见 [04](04-data-model.md)，接口见 [05](05-api-and-realtime.md)，Agent 细节见 [06](06-agent.md)。
> 所有可调数值集中在第 7 节。代码里不要硬编码，统一从配置读取。

## 1. 定位

- **邀请制的实时聊天社区**：只有持有邀请码的人能注册，社区内的人可以建频道、拉群、私信。
- **内置 Agent**：它可以读聊天记录并帮你总结、搜索、翻译、起草，经你批准后还能代你执行操作。
- **桌面优先**：以 ≥ 1280px 宽度的桌面浏览器为主，最低支持 1024px。手机布局放在 v1.1。
- **中文优先**：默认简体中文，另外提供英文。

## 2. 角色

| 角色 | 说明 |
|---|---|
| 访客 | 未登录，只能访问登录、注册（需邀请码）、找回密码、邀请预览页 |
| 成员 | 已注册、已验证邮箱的普通用户 |
| 站点管理员 | 可管理用户、邀请、频道、举报、审计日志和 AI 预算。第一个站点管理员用命令行创建 |
| 会话内角色 | 群主 `owner` / 管理员 `admin` / 成员 `member`，只对频道和群组有意义 |
| Agent | 机器人用户，不能登录，只能通过 run 发消息 |

## 3. 功能范围

标记说明：**M1–M7** 表示在哪个里程碑实现，都属于上线版；**v1.1** 表示上线后做；**✗** 表示明确不做。

### 3.1 账号与邀请
- M1：用邀请码注册（邮箱、用户名、显示名、密码）、邮箱验证、登录、退出、找回密码、Passkey 注册与登录
- M1：设备与会话管理（查看并注销其他设备）
- M1：生成、查看、撤销注册邀请码（设置页里的简单界面）
- M2：个人资料（显示名、头像、简介），用户名可修改（有冷却期）
- M7：注销账号
- v1.1：两步验证（TOTP）、屏蔽用户
- ✗：第三方登录（邀请制下意义不大）

### 3.2 会话
- M2：频道（创建、发现、加入、退出）、群组（创建、拉人、群邀请链接）、私信（与任何成员发起）
- M2：会话内角色与管理：改名、简介、头像、踢人、禁言、转让群主、归档
- M2：会话个人设置：置顶、免打扰、隐藏私信
- M4：Agent 会话（可以有多个）
- v1.1：话题线程（thread）、入群审批

### 3.3 消息
- M2：文本（Markdown 子集）、回复引用、编辑（24 小时内）、撤回（2 分钟内）、仅自己删除、管理员删除、系统消息
- M3：附件（图片、视频、音频、文件），支持拖拽、粘贴、上传进度；emoji 选择器；@提及（自动补全、高亮）
- v1.1：表情回应、置顶消息、收藏、转发、链接预览、语音消息、消息全文搜索界面
- ✗：音视频通话、端到端加密、阅后即焚

### 3.4 实时
- M2：即时送达、正在输入、在线状态（在线、离开、离线、最后在线时间）、已读位置与未读数、多标签页和多设备同步、断线补发、乐观发送与失败重试
- v1.1：私信已读回执

### 3.5 通知（M6）
- 浏览器推送：私信、@提及、回复我的、Agent 等待审批。
- 会话通知级别：全部 / 仅 @我 / 关闭，以及限时免打扰。
- 标题栏和应用角标显示未读数；桌面 PWA 可以安装成独立窗口。
- v1.1：邮件摘要。

### 3.6 Agent
- M4：Agent 会话、群内 @Agent、侧边助手面板、⌘K 命令面板和斜杠命令；只读能力（总结、搜索、翻译、起草、看图）；流式输出、停止、重新生成；用量配额。
- M5：需审批的操作（代发消息、定时消息、建群、拉人）；只影响自己的操作（提醒、记忆）不需要审批，但界面上看得到，也可以撤销；长期记忆；语义搜索。
- v1.1 起：联网（网页搜索、读取链接）、MCP 外部工具、用户自建 Agent。
- 详见 [06-agent.md](06-agent.md)。

### 3.7 管理（M7）
- 管理后台：用户（封禁、调整邀请名额、调整角色）、邀请、频道与群组、举报处理、审计日志、AI 用量与预算。
- 举报消息（所有成员可用）。
- v1.1：敏感词过滤。

## 4. 行为规则

### 4.1 注册与登录
- 注册页地址是 `/register?invite=<code>`。先校验邀请码，无效、过期或已用完都给出明确提示。
- 必填项：邮箱、用户名、显示名、密码。
- 密码至少 10 位，并拒绝常见弱密码。
- 必须验证邮箱才能登录。本地开发时，验证邮件在 Mailpit 里查看。
- 注册成功即消耗邀请码的一次使用次数，并记录"谁邀请了谁"。
- 登录方式是邮箱 + 密码，或 Passkey。会话 30 天滚动过期。
- 找回密码通过邮件链接，链接 1 小时后失效。

### 4.2 邀请
**注册邀请码**
- 站点管理员可以无限生成。
- 普通成员共有 5 个"成功邀请"名额：生成不消耗，有人用它注册成功才消耗。管理员可以为单个用户调整名额。
- 默认有效期 7 天、只能用 1 次，创建时可以调整。可以随时撤销。
- 数据库只存邀请码的哈希；明文只在创建时显示一次。

**群邀请链接**
- 只对已注册用户有效，不能用来注册账号。
- 默认有效期 7 天、次数不限，可以设置上限，可以撤销。
- 谁能创建由群设置 `who_can_invite` 决定：`all_members`（默认）或 `admins_only`。

### 4.3 用户资料
- **用户名**
  - 规则：3–20 位，小写字母、数字、下划线，全站唯一，用于 @提及。
  - 每 30 天可以改一次；旧用户名保留 30 天，不能被别人注册。
  - 保留名不能注册，比如 `admin`、`system`、`root`、`support`、`assistant`、`agent`，以及 Agent 的用户名和显示名。
- **显示名**：1–32 个字符，可以重复，支持中文和 emoji。
- **头像**：只能上传图片，服务端裁成正方形并生成多种尺寸。
- **在线状态**：社区成员互相可见。v1.1 再加"隐藏在线状态"的选项。

### 4.4 会话规则

| | 频道 | 群组 | 私信 | Agent 会话 |
|---|---|---|---|---|
| 谁能创建 | 任何成员 | 任何成员 | 任何成员（和对方） | 本人 |
| 谁能看到 | 全站成员（可在"发现"里搜到） | 仅成员 | 仅双方 | 仅本人 |
| 如何加入 | 自己加入 | 被拉入，或用群邀请链接 | 自动 | — |
| 名称 | 必填，全站唯一（忽略大小写） | 必填，可以重复 | 无（显示对方名字） | 自动生成，可以修改 |
| 成员上限 | 5000 | 500 | 2 | 1 个用户 + Agent |
| 允许 @Agent | 默认开启，群主可关闭 | 同左 | 不允许（请用 Agent 会话） | — |

- **私信**：同一对用户只有一个私信会话。私信不能"退出"，只能隐藏；对方发来新消息时自动取消隐藏。
- **退出与转让**：群主退出前必须先转让群主。最后一个成员退出时，会话自动归档。
- **归档**：会话变为只读，并从列表中移除。群主或站点管理员可以恢复。

### 4.5 消息规则

**正文**
- 用户消息最多 5000 字符，Agent 消息最多 20000 字符。
- Markdown 支持以下子集：
  - 支持：粗体、斜体、删除线、行内代码、代码块（带语言高亮）、链接（自动识别）、有序和无序列表、引用。
  - 不支持：标题（按普通段落显示）、图片（图片只能通过附件发送）、原始 HTML（一律当文本显示）。
  - 链接只允许 `http`、`https`、`mailto` 三种协议，并在新窗口打开。

**@提及**
- 在正文中存为 `<@user:UUID>`，显示时再换成当前的显示名，所以对方改名后，历史消息里显示的也是新名字。
- `@Agent` 同理，会触发一次 Agent 运行（见 06）。
- v1.1：`@所有人`。

**回复**
- 引用一条消息，显示发送者和摘要（前 100 字）。
- 被引用的消息如果已撤回或删除，显示"原消息已撤回"或"原消息已删除"。

**编辑**
- 只有发送者能编辑，时限 24 小时，编辑后显示"已编辑"。不保留编辑历史。

**撤回**
- 只有发送者能撤回，时限 2 分钟。
- 撤回后所有人看到"某某撤回了一条消息"，正文和附件文件从服务器真正删除。

**删除**
- 仅自己删除：超过撤回时限后，发送者或任何成员都可以把消息从**自己的视图**中移除，别人不受影响。
- 管理员删除：会话群主或管理员、站点管理员可以删除任何消息。所有人看到"此消息已被管理员删除"，正文和附件真正删除，并写入审计日志。

**系统消息**
- 在群组和私信中产生：成员加入、离开、被移出、会话改名、群主转让。
- 频道里成员加入和离开**不**产生系统消息，只反映在成员列表中，以免刷屏。

**显示规则**
- 同一发送者 3 分钟内的连续消息合并为一组，只在第一条显示头像和名字。
- 两条消息间隔超过 1 小时，插入时间分隔条。
- 未读消息上方显示"以下为新消息"分隔条。
- 离开底部阅读历史时，出现"回到最新"按钮，并显示期间的新消息数。

**发送体验**
- 发送时立即显示在界面上，状态为"发送中"。
- 失败时显示红色感叹号，可以重试或删除。
- 重试不会产生重复消息，靠幂等键保证。

### 4.6 附件

| 类型 | 识别方式 | 大小上限 | 展示方式 |
|---|---|---|---|
| 图片 | 按文件内容判断：jpeg、png、gif、webp、avif | 20 MB | 缩略图，点开大图预览；去除 EXIF 信息 |
| 视频 | mp4、webm（mov 在 Safari 可播放） | 100 MB | 内嵌播放器，不做转码 |
| 音频 | mp3、m4a、ogg、wav | 100 MB | 内嵌播放器 |
| 其他文件（含 svg、html、heic 等） | 其余所有类型 | 100 MB | 文件卡片，只能下载 |

- 每条消息最多 10 个附件；每人总空间 5 GB，超出时提示并拒绝上传。
- **图片处理**：重新编码原图以去除 EXIF（避免泄露拍摄地点），另外生成缩略图（最长边 480px）、预览图（最长边 1600px）和 thumbhash 模糊占位图。GIF 保留动画，只用第一帧生成缩略图。
- **下载权限**：只有上传者本人和附件所在会话的成员能下载。
- **清理**：上传后 24 小时内没有发出去的附件会被自动清理。
- v1.1：视频封面帧、HEIC 转换。

### 4.7 实时

**正在输入**
- 输入时最多每 3 秒通知一次；5 秒内没有新通知就自动消失。
- 显示为："某某正在输入…"，多人时显示"某某等 3 人正在输入…"。

**在线状态**
- 在线：至少有一个连接，且最近 5 分钟有操作。
- 离开：有连接，但 5 分钟无操作，或页面在后台。
- 离线：没有连接，显示"最后在线 X 分钟前"。
- 只订阅当前可见用户的在线状态，比如列表和成员面板里的人。

**已读与未读**
- 打开会话并滚动到底部时，把已读位置推进到最新消息的 seq。自己发出的消息自动算已读。
- 未读数 = 会话最新 seq − 我的已读 seq，超过 99 显示"99+"。
- 已读位置在多设备之间同步。

**断线补发**：断线重连后，按 `change_seq` 补齐漏掉的新消息、编辑和撤回，不重复、不遗漏。

### 4.8 通知（M6）
- **会触发推送的情况**：私信、@我、回复我的消息、Agent 等待我审批。
- **不推送的情况**：我正在查看该会话且页面在前台；会话设为"关闭"或处于免打扰时段。
- **推送内容**：发送者和一段摘要（最多 80 字），可以设置"不显示消息内容"。

### 4.9 搜索
- M2：搜索频道（发现页）、搜索成员（开私信、拉人时用）。
- M4：通过 Agent 搜索消息，关键词匹配，只在我有权限的会话中搜。
- M5：语义搜索（向量）。
- v1.1：独立的消息搜索界面。

### 4.10 设置
- **外观**：主题（浅色 / 深色 / 跟随系统）、强调色、透明度（清透 / 标准 / 着色 / 不透明）、减少动态效果、字号。
- **通知**（M6）：总开关、推送时是否显示内容、各会话的通知级别。
- **账号**：邮箱、密码、Passkey、登录设备、注销账号（M7）。
- **邀请**：我的邀请码和剩余名额。
- **Agent**：用量、长期记忆（查看、删除）、默认模式（快速 / 深度）。

## 5. 权限矩阵（频道和群组）

| 操作 | 成员 | 管理员 | 群主 | 站点管理员 |
|---|---|---|---|---|
| 发消息、@Agent | ✓（被禁言时不行） | ✓ | ✓ | 不是成员则不行 |
| 编辑、撤回自己的消息 | ✓ | ✓ | ✓ | — |
| 删除他人消息 | ✗ | ✓ | ✓ | ✓ |
| 拉人、建群邀请链接 | 看群设置（默认可以） | ✓ | ✓ | ✗ |
| 踢人、禁言 | ✗ | ✓（不能对管理员和群主） | ✓ | ✓ |
| 改名、简介、头像、设置 | ✗ | ✓ | ✓ | ✓ |
| 任免管理员、转让群主、归档 | ✗ | ✗ | ✓ | ✓（归档、恢复） |
| 查看成员列表 | ✓ | ✓ | ✓ | ✓ |

- **频道的例外**：非成员也能看频道简介和成员数，但加入之前不能看消息。
- **站点管理员的限制**：可以对任何会话做管理操作，每次都写审计日志。但**不能**读取自己不在其中的群组、私信、Agent 会话的消息内容。处理举报时，只能看到被举报的那一条消息，以及它前后各 5 条。

## 6. 非功能需求

| 项 | 要求 |
|---|---|
| 性能（本地） | 消息从发送到对方收到，p95 < 200 ms；首屏可交互 < 2 s；1 万条消息的会话滚动保持 60 fps |
| 性能（服务器） | 500 个并发 WebSocket 连接、每秒 20 条消息时，p95 < 300 ms（M7 用 k6 验证） |
| 浏览器 | 桌面版 Chrome、Edge、Safari、Firefox 的最近两个大版本 |
| 可访问性 | WCAG 2.2 AA；所有主要流程可以只用键盘完成；支持读屏 |
| 国际化 | 简体中文（默认）和英文。时间按浏览器时区显示，服务器一律存 UTC |
| 隐私 | 撤回和删除时真正清除内容；注销账号时清除个人数据，历史消息的发送者显示为"已注销用户"；日志不记录消息正文和 AI 对话内容 |
| 可靠性 | 消息不丢不重（幂等 + seq 补发）；Agent 运行可以恢复，不会重复执行有副作用的步骤 |

## 7. 默认值与可配置项

所有值都有配置默认值。标"后台可调"的，站点管理员可以在管理后台修改，存在 `app_settings` 表中。

| 配置项 | 默认值 | 后台可调 |
|---|---|---|
| 用户消息长度上限 | 5,000 字符 | 否 |
| Agent 消息长度上限 | 20,000 字符 | 否 |
| 撤回时限 | 2 分钟 | 是 |
| 编辑时限 | 24 小时 | 是 |
| 每条消息附件数 | 10 | 否 |
| 单文件上限 / 图片上限 | 100 MB / 20 MB | 是 |
| 每人存储空间 | 5 GB | 是（可按人调） |
| 未发送附件保留时间 | 24 小时 | 否 |
| 成员邀请名额（成功注册数） | 5 | 是（可按人调） |
| 注册邀请码默认有效期 / 次数 | 7 天 / 1 次 | 创建时可改 |
| 群邀请链接默认有效期 | 7 天，次数不限 | 创建时可改 |
| 群组 / 频道成员上限 | 500 / 5000 | 是 |
| 用户名改名冷却 / 旧名保留 | 30 天 / 30 天 | 否 |
| 密码最短长度 | 10 位 | 否 |
| 登录会话有效期 | 30 天（滚动） | 否 |

| 正在输入：发送间隔 / 自动消失 | 3 秒 / 5 秒 | 否 |
| 消息频率限制 | 每个会话 10 条 / 10 秒；全站 60 条 / 分钟 | 是 |
| 上传频率限制 | 30 次 / 小时 | 是 |
| 每用户 WebSocket 连接数 | 10 | 否 |
| Agent 每人每日 token | 500,000 | 是（可按人调） |
| Agent 单次运行（快速 / 深度） | 最多 8 步、120 秒 / 最多 16 步、300 秒 | 是 |
| Agent 全站月预算 | 20 美元（用到 80% 提醒，100% 暂停 Agent） | 是 |
| 消息合并阈值 / 时间分隔阈值 | 3 分钟 / 1 小时 | 否 |
